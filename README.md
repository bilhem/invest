# BF Properties — V1 (Phase 1 + Home)

    npm install
    npm run dev      # http://localhost:3000

Requires Node 18.18+ (20+ recommended).

- Replace images: `lib/images.ts` (set `src` to a file in `/public/images`).
- Edit home copy/data: `lib/content.ts`. Placeholders are marked `[X]`.
- Analytics hook: `lib/analytics.ts` (`track()`), CTAs use `components/CtaLink.tsx`.
- Other routes are stubs until Phase 3.
